## 引き継ぐ相談：黒電話のフックスイッチの配線

Pi 側で本人に伝えたこと（写真を見て、具体的な板ばねの場所を一緒に決めてほしい）：

1. **必ず壁の電話線から抜く**（待ち受け約48V、ベルのとき75V以上。Pi が壊れる）
2. 底のねじを外し、フック（受話器を置く台）の下にある **板ばねが重なった部品** を探す
3. 受話器の上げ下げで **くっつく・離れる2枚の組** を1つ選ぶ（テスターの導通チェック。なければ Pi で読んで確かめる）。取ったときにくっつく組でも離れる組でもよい（`.env` の `KOE_HOOK_PRESSED_IS_OFF_HOOK` で向きを合わせる）
4. その2枚の **元の線を外して** 黒電話のほかの回路から切り離し、新しい線（AWG26）をはんだ付け
5. 片方を **GPIO17（物理ピン11）**、もう片方を **GND（ピン9）**。3.3V・5V にはつながない。抵抗は要らない（内部プルアップ）

配線ができたら、**Pi の Claude Code で確かめる**（Skill `test-handset` の手順4。GPIO17 を見張り、本人が取る・置くを3回）。Mac から Pi に SSH するなら tailnet 名 `koe-dayori`。
