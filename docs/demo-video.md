# デモ動画の台本（下書き 11/7 夜）

撮影：11/8 15:00〜。自宅で、本人が **親（黒電話の受話器）** と **家族（スマホの LINE）** の2役をする。
長さの目安：**2分30秒〜3分**（提出フォームに長さの決まりがあれば合わせる。【要確認】）

審査で見られるところ（README の審査基準）：
- デモ 25%：「誰の、どんな課題を、どう解決するか」を**冒頭で**。前提知識のない人にも流れが分かる
- インパクト 30%：具体的なひとりと、その人を阻む壁
- Claude の活用 25%：基本を超えた使い方、Claude Code を開発の中心にしたこと

## 撮り方の工夫（2役なので）

- **親の場面と家族の場面は別々に撮り、編集でつなぐ**。LINE の画面はスマホの画面録画で撮る
- 親の場面は **手元と受話器と黒電話** を中心に撮る（顔は映さなくてよい）。声は受話器に向かって、ゆっくり話す
- 冒頭か最後に、字幕で一言「親の役は開発者本人が演じています」と入れる（正直に見せる）
- 先にLINEのテスト用グループのトーク履歴を消すか、新しいグループで撮ると画面がきれい
- 撮る前に `systemctl --user is-active koe-tunnel koe-dayori` が両方 active か、LINE の試験 API が 200 かを確かめる（受信が止まっていると撮り直しになる）

## 構成

### 1. つかみ（0:00〜0:20）「誰の、どんな壁か」

- 映像：実家の写真か、黒電話のアップ。字幕
- 字幕／ナレーション：
  「母はスマホを持っていません。家に Wi-Fi もありません。家族の LINE グループに、母だけがいません」
  「だから、母が使い慣れた **黒電話** を、LINE につなぎました」

### 2. 親 → 家族：受話器を取って話すだけ（0:20〜1:00）

- 親の場面：受話器を取る →「ピー」→ 話す → 受話器を置く → 本体が「送りました」
  - 話す内容（例）：「もしもし、たつや。お母さんです。今日は朝から膝が少し痛かったけど、昼から畑に出て大根を抜きました。週末に来るなら、お米を持って帰ってね」
- 家族の場面：スマホに LINE の通知 → 開くと、Claude の要約と、話した言葉がそのまま並んでいる
- 字幕：「文字起こしは Pi の中（faster-whisper）。要約と緊急度の判定は Claude が並列に」

### 3. 急ぎのときは、すぐ分かる（1:00〜1:20）

- 親の場面：「ちょっと転んで、腰を打った。立てるけど痛い」と話す
- 家族の場面：LINE に **⚠️ 急ぎ** の印つきで届く（緊急度の判定）
- 字幕：「雑談と、体調の異変を、Claude が見分けます」
- 【撮る前に確かめる】この文で実際に急ぎの判定になるか、1回試しておく

### 4. 家族 → 親：返事は受話器から聞ける（1:20〜2:00）

- 家族の場面：LINE で公式アカウントにメンションして返信「週末にお米取りに行くね。腰、無理しないでね」。できれば写真も1枚（孫やペット）
- 親の場面：本体のチャイム → モニターに「お便りが1件あります（たつやさんから）」→ 受話器を取ると読み上げ、モニターに本文と写真
- 字幕：「Claude が、親に聞き取りやすい言葉に言い換えます。写真は Claude が一言で説明」
- 家族の場面：LINE に「👂 お母さんが、たつやさんのお便りを聞きました」が届く

### 5. 見守り（2:00〜2:20）

- 映像：人感センサー（つないでいれば）と、毎晩20時の「📋 今日のお母さんの様子」の LINE 画面
- 字幕：「朝になっても動きがない、長い時間動きがない、を家族に知らせます」
- 【センサーをつないでいなければ】今日の様子の LINE 画面だけ見せ、センサーは「製品版で」と字幕で言う

### 6. Claude Code で作った（2:20〜2:45）

- 映像：Pi の画面で Claude Code が動いているところ、`.claude/` の中身
- 見せること（docs/claude-code-log.md から選ぶ）：
  - **Skills**：受話器の確認（test-handset）、お便りの試し（try-letter）、配備（deploy-koe）
  - **フック**：秘密情報を Git に入れないための確認（`.claude/hooks/check_secrets.py`）
  - **サブエージェントの構成**：アプリの中で、要約・緊急度・言い換え・写真・今日の様子を役割ごとの Claude に分けた
  - **試行錯誤**：LINE の返信が届かない → Claude Code が Funnel・Cloudflare・TLS を切り分け、受け口を替えて URL の自動登録まで作った（11/7）。文字起こし 79.5秒 → 13秒

### 7. しめ（2:45〜3:00）

- 映像：受話器を置く手元。字幕
- 「スマホを持たなくても、家族の輪の中に」
