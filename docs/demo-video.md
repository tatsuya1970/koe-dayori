# デモ動画の台本（決定版 11/8 午前）

11/7 夜に Pi で作った下書きと、Mac で作った案（主催の「デモ動画の撮影と提出」ガイドに合わせたもの）を1つにまとめた。

- 撮影：11/8 15:00〜。自宅で、本人が **親（黒電話）** と **家族（スマホの LINE）** の2役
- 長さ：**3分以内**（提出フォーム）。超えた分は審査員に見られないので **2:50 で終える**
- 音の入出力：**スピーカーフォン**（11/8 決定。README「決定の変更」）。受話器を取る・置くは黒電話のフックスイッチ。スピーカーフォンは黒電話の後ろか中に置く

## 主催ガイドから守ること

- 動画は **ピッチ**。「根本的な課題」「技術的な解決」「実際の実装」をはっきり。**コードの画面に終始しない**
- ゴールは審査員に **「もっと見たい」** と思わせること。**いちばん大事なことを冒頭に**
- 音声は外付けマイクかヘッドセットで、静かな部屋で。画面は **1080p 以上**、全画面で Dock を隠す。**おやすみモード** で通知を止める

## 審査で見られるところ

- インパクト 30%：具体的なひとりと、その人を阻む壁
- デモ 25%：誰の、どんな課題を、どう解決するかを冒頭で。前提知識のない人にも流れが分かる
- Claude の活用 25%：基本を超えた使い方、Claude Code を開発の中心にしたこと
- 深さと実行力 20%：試行錯誤と、実際に動いていること

### 1. つかみ（0:00〜0:20）

**画**
- 黒電話の全景（真上かやや斜め上から。背景は明るい無地）
- 手が受話器を取る →「ピー」→ 話す → 置く（3秒ずつに縮める）
- スマホに LINE の通知が届く（画面録画）

**字幕／ナレーション**
> 母はスマホを持っていません。家族の LINE グループに、母だけがいません。
> だから、**黒電話** を、LINE につなぎました。

**字幕（小さく、最初か最後）**：「親の役は開発者本人が演じています」

### 2. 親 → 家族：受話器を取って話すだけ（0:20〜0:55）

**親の場面**：受話器を取る →「ピー」→ 話す → 受話器を置く → 本体が「送りました」、モニターに **「✓ 送りました」と要約**
- 話す内容（例）：「もしもし、お母さんです。年末はいつ帰るの？」
- 黒電話とモニターが一緒に入る画角で

**家族の場面**：スマホに LINE の通知 → 開くと、Claude の要約と、話した言葉がそのまま並んでいる

**字幕**：「文字起こしは電話機の中（Raspberry Pi・faster-whisper）。要約と緊急度の判定は Claude が並列に」
**編集**：受話器を置いてから届くまでの待ち時間は切り、「約20秒後」と字幕

### 3. 急ぎのときは、すぐ分かる（0:55〜1:10）

**親の場面**：「ちょっと転んで、腰を打った。立てるけど痛い」と話す
**家族の場面**：LINE に **🚨【至急】** の印つきで届く
**字幕**：「雑談と、体調の異変を、Claude が見分けます」
**撮る前に**：この文で実際に至急になるか、1回試す

### 4. 家族 → 親：返事が電話から聞こえる（1:10〜1:50）★山場

**家族の場面**：LINE で「@声だより」にメンションして返信「年末は29日に帰るよ。腰、無理しないでね」。写真も1枚（自分で撮った風景か、了承を取ったもの）
**親の場面**：本体の「ポーン」→ モニターに「お便りが2件あります（たつやさんから）」→ 受話器を取ると読み上げ、モニターに本文と写真（Claude の一言の説明つき）→「ピー」のあと返事「ありがとう、待ってるよ」→ 置く
**家族の場面**：LINE に返事の要約と「👂 お母さんが、たつやさんのお便りを聞きました」
**字幕**：「Claude が、親に聞き取りやすい言葉に言い換えます。写真は Claude が一言で説明」「いきなり鳴らさず、留守番電話のように、受話器を取ったときに聞ける」
**編集**：黒電話とモニター（左）、LINE（右）の **2分割**。読み上げには字幕をつける

### 5. 見守り（1:50〜2:05）

- 人感センサーをつないでいれば、手をかざして反応するところと、「📋 今日のお母さんの様子」の LINE 画面
- 字幕：「朝になっても動きがない、長い時間動きがない、を家族に知らせます」
- 時刻を早めて撮るときは、字幕「デモのため時刻を早めています」
- **間に合わなければこの場面は削り**、4 と 6 に時間を回す

### 6. Claude Code で作った（2:05〜2:35）

コードの画面は1つにつき数秒。字幕で要点を言う。
- **構成図**（静止画8秒）：受話器 → Pi（文字起こし）→ Claude（要約・緊急度を並列）→ LINE ／ LINE → Pi → Claude（言い換え・写真の説明）→ 電話とモニター ／ センサー → Claude（いつもと違う）→ 今日の様子
- **Pi の上で動く Claude Code**（Mac から SSH した画面）
- **Mac と Pi の2つの Claude Code の分担**：黒電話の改造は、写真を Mac の Claude Code に見せながら配線を決めた（`docs/handoff-2026-11-07.md` で引き継ぎ）
- **フック**：わざと `.env` をコミットしようとして止められる画面（5秒）
- **一番詰まった場面**：「LINE の返信が届かない → Claude Code が2つの入口を同じ時刻に比べて原因を絞り込み、受け口を替え、URL の自動登録まで作った」（字幕3行）。文字起こし 79.5秒 → 13秒も字幕で一言
- Skills（test-handset など）は時間があれば

### 7. しめ（2:35〜2:50）

- 受話器を置く手元 → 黒電話の全景、タイトル「声だより」と GitHub の URL
- 字幕：
  > スマホを持たなくても、家族の輪の中に。
  > 製品版は LTE を入れて、コンセントに挿すだけで。受話器の中で聞いて話せる形に。
- 小さく：「試作では、声の入出力を電話機の横のスピーカーフォンで代用しています」

## 撮影の前に

- [ ] `systemctl --user is-active koe-tunnel koe-dayori` が両方 active。LINE で試しに1通送って、お便りが届くことを確かめる
- [ ] 試しのお便り（「Tatsuya Takemura」名義など）を消す。モニターの「これまでのお便り」に映るため
- [ ] LINE のテスト用グループのトーク履歴を消すか、映らない位置までスクロール。名前とアイコンも確認
- [ ] 本番を起動してから受話器を取る（起動前に上げていると反応しない）。「送りました」を聞き終えてから次に取る（音が重なると出せない）
- [ ] iPhone：集中モード（おやすみ）をオン、**LINE だけ通知を許可**。画面収録をコントロールセンターに出す
- [ ] Mac：おやすみモード、収録するウインドウは全画面、Dock を隠す（⌘ + option + D）、ターミナルの文字を大きく
- [ ] カメラは横向き・三脚で固定、1080p 以上。部屋を明るく、黒電話の背景は明るい色
- [ ] モニターの明るさを上げ、反射が映らない角度にする

## 撮り方のコツ

- 親の場面と家族の場面は別々に撮り、編集でつなぐ
- 1つの場面を3回ずつ撮る。話す前と後に2秒ずつ間を取る
- ナレーションは、映像を並べたあとに静かな部屋で別に録る（QuickTime の「新規オーディオ収録」）
- 字幕は短く、1画面1行。音を消して見ても話がわかるように
- 道具：Mac の画面は QuickTime、iPhone は画面収録、編集は iMovie（2分割は「ピクチャ・イン・ピクチャ」→「横に並べる」）
